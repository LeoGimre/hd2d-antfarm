# REQUESTS.md — Leo's suggestion box

This file is **yours**, Leo. Drop notes here any time. The loop reads it at the start of every tick
and folds unprocessed notes into what it picks up next.

**The loop never writes to this file.** It records which notes it has consumed in `state/STATE.md`
instead, so this stays a clean one-way channel. You never have to reply to anything.

Notes are strongest when they're about *direction* ("battles feel too slow", "more weird creatures,
fewer cute ones") rather than implementation — the loop is better at deciding how than at deciding
what's fun.

Format: one note per `##` heading. Anything under a heading is the note.
